# CHAEUN
친구와 운동을 기록하고 꾸준함을 함께 쌓는 모바일 웹앱입니다.

## 이번에 추가한 기능
- 타이머 시작·일시정지·재개·초기화, 백그라운드 및 새로고침 후 경과 시간 복원
- 타이머 시간을 운동 기록으로 가져오기 (기록 저장 성공 후 초기화)
- 본인 운동 기록의 종류·시간·메모 수정 및 삭제
- 이름, 주간 운동 목표, 순위 공개, 친구 깨우기 수신 설정 저장
- 연속 주간 목표 달성 → 연속 운동일 → 누적 시간 순위
- 챌린지 만들기·참여·참여 취소, 참여자별 달성률과 종료 상태
- 기록이 없는 친구도 포함하는 클럽 멤버 목록과 당일 미운동 친구 깨우기
- 깨우기 알림 읽음 처리
- CHAEUN 화면 제목·로그인 브랜드·아이콘·알림 이름 적용

## 동작 기준
시간은 한국 시간 기준입니다. 같은 날 여러 운동은 운동일 1일로 계산합니다.
하루가 끝나기 전에는 어제까지의 연속 운동일이 유지됩니다.
주간 목표의 기본값은 3일이고 변경은 다음 주 월요일부터 적용됩니다.
이전 주 목표 이력을 보관하므로 이후 목표 변경이 과거 순위를 바꾸지 않습니다.
기록 수정·삭제는 순위와 챌린지 계산에 반영됩니다.
챌린지는 시작일 포함, 종료일 다음 날 자정 미포함으로 계산합니다.
참여 전이라도 챌린지 기간 안의 해당 운동 기록은 포함됩니다.
타이머는 브라우저가 계속 실행되도록 강제하는 방식이 아니라 저장한 시각으로 경과 시간을 복원합니다.
브라우저 저장소를 삭제하면 타이머 상태도 삭제됩니다.
운동 기록·사진·챌린지는 같은 초대 코드의 클럽에만 공유됩니다.
순위 비공개는 순위 목록에서만 숨기며 공유한 피드는 숨기지 않습니다.
삭제한 기록의 사진은 즉시 접근할 수 없게 되고, 저장소 삭제 오류가 나면 정리 대기열에서 다음 기록 조회·삭제 때 재시도합니다.

## 아직 별도로 필요한 작업
- Cloudflare 계정·D1·R2를 연결한 실제 게시 및 운영 환경 검증
- 기존 회원가입·로그인·친구 초대의 전체 흐름 검증과 운영 인증 성능 확인
- 앱을 완전히 닫았을 때 받는 Web Push 알림 연결
- 비밀번호 재설정 (현재 로그인 화면에서도 미지원 안내)

실제 게시 완료나 외부 서비스 검증 완료를 의미하지 않습니다. 이 버전은 로컬 구현입니다.

## 확인 결과
- TypeScript 검사와 운영용 빌드 통과
- 시간·주간 목표·연속일·챌린지 계산 테스트 5개 통과
- 별도 로컬 데이터베이스에서 기록 수정·삭제 권한, 클럽 분리, 설정 저장, 챌린지 생성·참여·취소와 재계산, 알림 읽음 및 중복 방지 테스트 통과
- 새 기능 API 검사는 로컬 테스트 세션을 사용했으므로 회원가입·로그인 전체 흐름의 검증을 대신하지 않습니다.

## 로컬 실행
Node.js 22.13 이상이 필요합니다.

```sh
npm run install:ci
npm run db:migrate:local
npm run dev
```

데이터베이스는 Wrangler가 drizzle 폴더의 SQL 파일 순서로 관리합니다.
Drizzle의 과거 스냅샷에서 마이그레이션을 재생성하지 마세요.

```sh
npm run test:features
npx tsc --noEmit
npm run build
```
